# Requirements checklist (from docs/assignment/ASSIGNMENT.md)

This is the tracking checklist. The **one-page requirements document** Incubyte asks for is a separate file, `docs/requirements-one-pager.md`, and must be written and committed BEFORE any application code.

## Must deliver
- [ ] One-page requirements doc, committed first: goal, scope and features, what is deliberately left out, and why
- [ ] Web app for the HR Manager to manage salary data for 10,000 employees across multiple countries
- [ ] HR Manager can answer questions about how the org pays people (insights, not only CRUD)
- [ ] Backend in the role's stack: Node.js with TypeScript
- [ ] Relational database (SQLite is named as acceptable)
- [ ] UI in React or Next.js, with a component library
- [ ] Seed script that creates 10,000 employees
- [ ] Deployed and fully functional (public URL)
- [ ] Video demo

## Quality bar
- [ ] Meaningful unit tests covering core functionality
- [ ] Tests fast, deterministic, easy to understand
- [ ] Clean structure, readable, maintainable
- [ ] Incremental commits that show how the solution evolved
- [ ] Not the most complex system: good engineering judgment

## Artifacts to commit
- [ ] Requirements document
- [ ] Planning or design notes
- [ ] Architecture diagram
- [ ] Prompts or instructions used with AI tools
- [ ] Trade-off explanations
- [ ] Performance considerations (10,000 rows: pagination, indexes, aggregate queries)

## Submission
- [ ] Code in a Git repository Incubyte can open
- [ ] Reply to Incubyte's email with the repo link (plus the deployed URL and the video link)
