# Requirements checklist (from docs/assignment/ASSIGNMENT.md)

This is the tracking checklist. The **one-page requirements document** Incubyte asks for is a separate file, `docs/requirements-one-pager.md`, and must be written and committed BEFORE any application code.

## Must deliver
- [x] One-page requirements doc, committed first: goal, scope and features, what is deliberately left out, and why
- [x] Web app for the HR Manager to manage salary data for 10,000 employees across multiple countries
- [x] HR Manager can answer questions about how the org pays people (insights, not only CRUD)
- [x] Backend in the role's stack: Node.js with TypeScript
- [x] Relational database (SQLite is named as acceptable)
- [x] UI in React or Next.js, with a component library
- [x] Seed script that creates 10,000 employees
- [ ] Deployed and fully functional (public URL)
- [ ] Video demo

## Quality bar
- [x] Meaningful unit tests covering core functionality
- [x] Tests fast, deterministic, easy to understand
- [x] Clean structure, readable, maintainable
- [x] Incremental commits that show how the solution evolved
- [x] Not the most complex system: good engineering judgment

## Artifacts to commit
- [x] Requirements document
- [x] Planning or design notes
- [x] Architecture diagram
- [x] Prompts or instructions used with AI tools
- [x] Trade-off explanations
- [x] Performance considerations (10,000 rows: pagination, indexes, aggregate queries)

## Submission
- [ ] Code in a Git repository Incubyte can open
- [ ] Reply to Incubyte's email with the repo link (plus the deployed URL and the video link)
